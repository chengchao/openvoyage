# OpenVoyage 引擎计划（兼容《大航海時代 II》DOS 中文版数据）

目标：用 Godot 4.x + GDScript 完整复刻（六主角剧情、贸易、海战、港口全系统），直接读取玩家本地的原版 KOUKAI2 数据文件作为资产来源。

三条铁律（来自需求）：

1. **每次 commit 后 repo 都是可玩的游戏**
2. **每次 commit 都有完整的测试与验收**
3. **TDD：先写测试，后写实现**

---

## 0. 法律边界

repo 中**不包含任何原版资产**。原版数据由用户提供本地 `KOUKAI2/` 目录，经离线转换管线（§0.5）转为 Godot 资源后置于 **untracked 目录**（转换产物是衍生品，与原档同等对待，不进 repo、不进 CI）。测试用的固定数据（golden file）只存哈希值和少量自制样本，不存原版字节。复刻仅供个人学习使用。

## 0.5 数据策略（两轮评估的结论）

**评估一：数据层先行？** 部分先行——只对"已破解、可黄金测试"的部分（LS11、图像、PORTMAP、ZA_DAT、MES、WINDCUR、MML 偏移表）先行，限时一个 2–3 周 sprint；SNR 字节码只做**普查**（指令直方图、操作数范围、静态遍历）不做实现；COLONY/TRANSIT 字段语义、碰撞分界、调色板、码表由玩法里程碑拉动。理由：先行部分 TDD 性价比最高且能全局排雷；但语义未明的数据先猜结构必返工，且纯数据层超过 3 周会掉进"框架陷阱"。

**评估二：转成 Godot 常用格式？** 转，但分三类：

| 数据类 | 策略 | 理由 |
|---|---|---|
| 图像/图块/地图/音乐 | **离线转换**：PNG、TileSet(.tres)、JSON、MIDI/ogg | 格式已定型；换取 Godot 工具链（TileMap/动画编辑器、Inspector）与**可修补性**——后期调色板校准、码表补字、碰撞标注都改在转换产物上，diff 友好 |
| 数值表（ZA_DAT/COLONY/TRANSIT） | 转 JSON / typed Resource，schema 带版本号 | 字段语义随玩法迭代，留改口 |
| SNR 剧本字节码 | **不转**，运行时解释 | 语义仍在逆向中，转 AST 等于固化未知；M12 吃透后再考虑编译中间格式 |

转换器用 **Python** 写（复用已验证的 `koukai2-docs/tools/ls11_extract.py`），pytest 黄金测试；后期可升级为 Godot `EditorImportPlugin`（把 KOUKAI2 目录扔进工程即自动导入）。游戏代码从第一天起**只见 Godot 资源、不见 LS11**。

配套要求：**自制占位资产包**提前到 M0 成为必需品——CI 没有原版资产，冒烟验收用占位包跑通全流程；本地开发用真资产跑全量验收（哈希清单等测试标记 skip-if-missing）。

## 1. 工程基座（第一周，M0 里程碑的内容）

| 项 | 选型 |
|---|---|
| 引擎 | Godot 4.x LTS，GDScript |
| 测试框架 | GUT（单元 + 集成），全部可 `godot --headless` 运行 |
| CI | GitHub Actions：每次 push 跑 ①全部 GUT 测试 ②冒烟验收（见下） ③导出 Linux/macOS 构建 |
| 钩子 | pre-commit 本地跑测试，红灯禁止 commit |
| 数据参照 | 已有逆向文档 `koukai2-docs/`（LS11 算法、ZA_DAT、SNR 字节码、像素格式均已破解并验证），`tools/ls11_extract.py` 作为导入器的参照实现 |

### 「可玩」的机器定义（每个 commit 强制执行）

CI 中的**冒烟验收测试**就是可玩性的定义，随里程碑逐步加严：

```
smoke_test.gd（headless 自动化）:
  启动游戏 → 到达主菜单 → 开新游戏 → 执行当前里程碑的核心循环
  （如：在港口走 10 步 → 进酒馆 → 关对话 → 存档 → 读档）→ 无报错退出
```

冒烟脚本模拟输入事件驱动真实场景树，不 mock。它失败 = 这个 commit 不可玩 = CI 红灯。

### TDD 工作流（每个功能一致）

```
红：写失败测试（单元：纯逻辑类；验收：冒烟步骤或集成场景）
绿：最小实现
重构：场景与逻辑分离保持成立
commit：信息格式 "M3: 港口行走碰撞 [tests: 12 new, all green]"
```

### 架构原则（为了可测试性）

- **逻辑与表现分离**：经济、航海、战斗、脚本解释器全部是不依赖场景树的纯 GDScript 类（`RefCounted`），headless 直接实例化测试；Node/场景只做渲染和输入。
- **数据转换层**（`converter/`，Python，见 §0.5）：原版档→Godot 资源的离线管线，各格式独立、各有 pytest golden 测试；游戏代码只消费 Godot 资源。SNR 字节码例外：运行时解释。
- **固定随机种子**：模拟系统全部注入 RNG，测试可复现。

## 2. 里程碑（每个 = 一串 commit，结尾 repo 比上一个里程碑「多一块可玩内容」）

每个里程碑列出：交付物 / 新增验收（并入冒烟测试，永久生效）/ 典型 TDD 测试。

### M0 可启动的空游戏（walking skeleton）
- 交付：主菜单场景、"开始/退出"、CI、GUT、冒烟框架、**占位资产包 v0**（CI 用）、转换资产目录约定（untracked）
- 验收：headless 启动到主菜单并退出，exit code 0（CI 用占位包）
- 测试：配置加载单元测试；冒烟：菜单可达

### M1 转换管线 ①：LS11 + 容器解析（Python）
- 交付：`converter/` Python 包——LS10/LS11 解压（复用 `ls11_extract.py`）+ ZA_DAT/MES/MESSAGE/MENU/PORTMAP/WINDCUR/MML 偏移表解析 → JSON；一键命令 `convert.py <KOUKAI2目录> <输出目录>`
- 验收：对全部 14 个 LZW 容器逐块解压且字节数与头部声明一致（~560 块）；JSON 输出过 schema 校验；SNR 字节码**普查报告**（指令直方图、C8/CC 操作数范围、静态遍历不崩）
- 测试（pytest golden）：自制小样本逐字节比对；原版档「大小+SHA256 清单」校验（本地跑，CI skip）
- Godot 侧不变，M0 冒烟仍过——铁律 1 成立

### M2 转换管线 ②：图像→PNG/TileSet + 资料查看器
- 交付：两种像素布局（8 像素单元 4 平面交错 / 图块平面顺序 128B）→ PNG；KAO 头像图集、PORTCHIP 7 组 TileSet(.tres)、IAP 精灵图集（8 字节目录→AtlasTexture 元数据）；调色板先近似 EGA 后续校准；Godot 内置「资料查看器」调试菜单浏览转换产物
- 验收：转换产物数量断言（256 头像、7×240 图块、101 张港图）；冒烟新增：查看器随机打开 10 项无错（CI 用占位包同结构资产）
- 测试：pytest 逐像素 golden（自制样本）；Godot 侧加载层单元测试

### M3 港口场景：地图渲染 + 行走
- 交付：PORTMAP(96×96) + CHIP_NO 选图块组 → TileMap；主角行走、碰撞（按图块属性分界值）、镜头跟随
- 验收（并入冒烟）：开新游戏出生在里斯本港，向四方向各走 10 步，不能穿墙
- 测试：地图解析单元测试；碰撞规则纯逻辑测试（给定图块号→可否通行）；集成：模拟输入走固定路线断言坐标

### M4 设施进入：ZA_DAT + 设施框架
- 交付：ZA_DAT 解析（101 港 × 12 设施坐标）；走到门口坐标触发设施场景（背景占位 + IAP 店员立绘 + 菜单框架，功能先空）
- 验收：冒烟新增「走到酒馆门口→进入→看到店员→退出」
- 测试：ZA_DAT 解析（全坐标 <96 或 FFFF）；触发判定纯逻辑测试；每设施可进可出

### M5 文本与对话系统
- 交付：MES/MESSAGE/MENU 解析（偏移表、$ 变量、说话人行、0A/00 控制码）；对话窗 UI（头像 + 名字栏 + 逐字显示）；字模问题先用系统 CJK 字体 + 码表占位（原版自定义编码→可显示文本的映射表作为独立数据文件，逐步完善）
- 验收：冒烟新增「进酒馆→老板娘说出第一句台词→按键关闭」
- 测试：MES 解析 golden（条数：SNR1=1176 等）；$ 变量替换单元测试；UI 集成测试断言文本逐字出现

### M6 世界地图与航海（第一个"游戏感" commit 群）
- 交付：WORLDMAP 渲染、出港/入港、舰队在海上移动、日期推进、补给（水/粮）消耗
- 验收：冒烟新增「里斯本出港→海上航行 5 天→回港」；补给耗尽触发警告
- 测试：地形判定（海/陆）、移动消耗公式、日期系统全部纯逻辑 TDD；集成：固定路线航行断言到达日期

### M7 风与海流
- 交付：WINDCUR 格网解析（高低半字节=风/流），航速受风向影响，季节变化
- 验收：顺风明显快于逆风（冒烟断言两次航行天数差）
- 测试：格网解码 golden；航速公式参数化测试（先按合理猜测立公式，后与原版行为校准——校准本身写成对照测试清单）

### M8 贸易经济
- 交付：交易所买卖、COLONY/TRANSIT 数据驱动的物价、距离差价、市场占有
- 验收：冒烟新增「买 10 桶酒→航行到塞维利亚→卖出→金币增加」
- 测试：价格公式、稀缺度、讨价还价全部纯逻辑 TDD；经济守恒性质测试（无中生有检测）

### M9 船只、舰队与船员
- 交付：造船所（买船/改装）、船员雇佣、职位（航海士/会计…）、船数据表
- 验收：冒烟新增「买一艘巴沙船→编入舰队→出港」
- 测试：载重/船速/耐久计算；舰队聚合属性；边界（0 船员、满载）

### M10 存档/读档
- 交付：全状态序列化（自有 JSON/二进制格式，非原版格式）、多槽位
- 验收：冒烟新增「做一串动作→存档→重启进程→读档→状态一致」（这是最有价值的回归网）
- 测试：所有系统的 round-trip 性质测试（随机状态→存→读→相等）

### M11 海战与决斗
- 交付：回合制海战（接舷/炮击/撤退）、CHAR.LZW 单位渲染、风对战斗影响、剑术决斗
- 验收：冒烟新增「遭遇海盗→自动战斗→结算（胜/逃皆可，无崩溃）」
- 测试：命中/伤害公式、士气、AI 决策树全部纯逻辑；战斗可从任意中盘状态构造（fixture）

### M12 SNR 脚本解释器（剧情引擎）
- 交付：SNDT 容器解析、章节事件入口表、字节码 VM（C8 台词/CC 头像/C7 等待已实证；C0/AC/AD 等控制流边做边逆向，未知指令打日志跳过并告警）
- 验收：冒烟新增「开新游戏（若昂线）→ 序章开场对话完整播完→获得操作权」
- 测试：VM 是纯逻辑类——每条指令一组 TDD 测试；用自制迷你脚本测分支/跳转；对原版 SNR1 做「全脚本静态遍历不崩溃、所有 C8 操作数在 MES 范围内」性质测试
- ⚠ 风险最高的里程碑：未解指令语义靠对照原版 DOSBox 行为补全，逆向所得随时回写 `koukai2-docs/`

### M13 事件与剧情推进
- 交付：EVENT*.DAT、旗标系统、条件触发（进港/进设施/日期）、章节推进、多主角选择界面
- 验收：冒烟新增「若昂线打到第一章结束的标志性事件」；其余主角线可开局
- 测试：触发条件矩阵纯逻辑测试；旗标存读档回归；「剧情可达性」批量模拟测试（脚本驱动快进）

### M14 音频
- 交付：D2.MML 解析（LE16 偏移表、每曲 4 声道）→ 两条路线择一：①MML→MIDI 离线转换 ②运行时软件 OPL2（如集成 ymfm GDExtension）；音效占位
- 验收：主菜单/港口/航海各有正确曲目循环播放（冒烟：音频流非空断言）
- 测试：MML 解析 golden（曲目数、声道偏移）；音符事件流快照测试

### M15 片头、结局与完成度收尾
- 交付：OPGRAPH 片头幻灯、ENDGRP+PUT 表结局播放、全六主角线验收、平衡校准清单、本地化码表补全
- 验收：六条线各自动快进通关一次（夜间 CI 长测试）；手动验收清单签字
- 测试：PUT 指令表解析；通关模拟器（脚本化输入序列）

## 3. 节奏与规模估计

- M0–M5：每里程碑约 1–2 周（单人业余）；M6–M11：各 2–3 周；M12–M13 最难，预留 4–6 周；M14–M15 各 1–2 周。总计约 8–12 个月业余时间。
- commit 粒度：一个 TDD 循环（或几个相关循环）= 一个 commit，每天结束必须绿灯——做不完的功能用 feature flag 关掉，保证铁律 1。
- 每里程碑结束打 tag（`v0.3-port-walk`），CI 产出可下载构建。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| SNR 未解指令多 | M12 前置一个「指令普查」spike：统计全部 SNR 的字节码直方图，按出现频率排序逐个攻破；DOSBox-X 调试器对照 |
| 文本编码→可读文字的码表工程量 | 把码表做成社区可协作的 CSV；先渲染原版字模位图（DATA1 中疑似字库）保证可玩，码表慢慢补 |
| 原版公式未知（航速/物价/战斗） | 每个公式建「对照实验记录」：原版同条件实测→写成参数化测试→调参到通过 |
| 范围失控 | 铁律 1 天然防烂尾：任何时刻停下来都有一个能玩的游戏 |

## 5. repo 结构

```
repo/
  converter/       # Python 转换管线（LS11、图像、表格→PNG/TileSet/JSON）+ pytest golden
  placeholder/     # 自制占位资产包（CI 冒烟用，可入 repo）
  godot/           # Godot 工程
    res://
      data/        # 薄加载层（读转换产物或占位包，运行时切换）
      sim/         # 经济、航海、战斗、日期、SNR 脚本 VM（纯逻辑，全 TDD）
      game/        # 场景、UI、输入（薄壳）
      tests/       # unit / integration / smoke
      tools/       # 资料查看器、通关模拟器、码表编辑器
  assets-converted/  # 转换产物（untracked，.gitignore）
  docs/            # 即 koukai2-docs，逆向新发现持续回写
```
