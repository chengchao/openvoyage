## 基本信息

- 游戏：大航海時代 II（光荣 KOEI，1993/1994，IBM PC DOS 移植，中文版）
- 主程序由 Microsoft C（1990 年版运行库，约 MSC 5.1/6.0）编译，混合手写汇编图形库
- 显示模式：VGA mode 12h（640×480、16 色、4 位平面）
- 音频：AdLib / OPL2（端口 388h/389h）
- 中文显示依赖外部中文 DOS 系统的字型服务（int 15h AX=5000h，16×16 点阵）
