# 02 可执行文件分析

## 2.1 KOUKAI2.COM —— 启动器 / 驻留服务（776 字节）

纯手写汇编。文件布局：

| 偏移(内存) | 内容 |
|---|---|
| 0x100 | `jmp 0x392`（入口跳转） |
| 0x103–0x112 | 驻留指针表（驻留段、数据段、原显示模式等，经 int 65h 暴露） |
| 0x113–0x13D | 文件名表：`FMDRV.COM` `OPEN.EXE` `MAIN.EXE` `PW.EXE` `END.EXE` |
| 0x13E–0x17B | 两条错误讯息（磁盘错误 / 内存不足） |
| 0x216–0x22x | int 65h 功能跳转表 |
| 0x2AB–0x2E6 | int 24h（严重错误）处理：保存 GC 寄存器→显示讯息→等回车→`AL=1` 重试 |
| 0x2E7–0x391 | int 65h 服务分发器 + 参数块拷贝例程 |
| 0x392–0x47x | 主流程（见文档 01 §1） |

EXEC 子程序使用 `int 21h AX=4B00h`，参数块在 0x103；每次 EXEC 失败会显示 `<名> : cannot execute.` 等四种诊断文本。

## 2.2 MAIN.EXE —— 游戏主体（298 561 字节）

- MZ 头：头部 20 992 B，重定位 5231 条（6 个目标段，最大段 0x43B4），入口 `0000:3374`
- 入口序列是 **Microsoft C 运行库**（字符串 `MS Run-Time Library - Copyright (c) 1990, Microsoft Corp`）：`AH=30h` 版本检查 → 建立近堆/远堆 → `__astart`
- 二进制内嵌完整资源文件清单（C 字符串常量，均带 `C:` 盘符前缀），其中有 **7 个文件不在本拷贝中**：`DATA2.LZW`、`EVENT.LZW`、`IKKI.LZW`、`SNRDAT.LZW`、`SNRMES.LZW`、`MOUSE.COM`、`USERNAME.DAT`——前几个是发行盘上的合并压缩包（安装时解成 EVENT*.DAT / SNR*.* 散档），`USERNAME.DAT` 为存档时创建，`IKKI.LZW` 疑似与舰队战画面相关
- 大量 `printf` 风格格式串（`%4d/%2d/%2d`、`%-14s %3d%%`、`%2d:%02d %c.M` 等）说明状态栏/账目/航海仪表的渲染走 C 格式化输出
- 字符串 `KOEI Game %02d` 与 ` RPSWV`：与存档槽显示有关
- 链接了与 OPEN/END 相同的汇编图形库（见 2.5）

## 2.3 OPEN.EXE —— 片头（45 179 字节）

- 入口 `0000:2D1E`，同款 MS C 运行库
- 仅引用一个资源：`C:OPGRAPH.LZW`（LS10 容器，14 幅全屏图，最大解压后 56 051 B）
- 包含完整的 **LS 解压器 C 代码**（本次逆向的算法即从此处反汇编恢复，见文档 03）：
  - `0x26C4`（映像偏移）：位流取码例程 getcode
  - `0x87E4 / 0x89C9–0x8A4C`：解压主循环（字面量 vs 回溯拷贝）
  - `0x8A4F`：按索引读 LZW 容器条目（`条目表 = 0x110 + 12×n`）
- 片头播放器是一个小型脚本解释器：`0x386D` 处按键码 `0x3B–0x53`（F1–?）做跳转分发，回车可跳过

## 2.4 END.EXE —— 结局（44 697 字节）

结构与 OPEN.EXE 几乎一致（同运行库、同图形库、同解压器，`cmp si,100h` 特征位于映像 0x18A1）。资源：ENDGRP.DAT（结局图档库，60+ 块）、END_PUT.DAT、HDAT.PUT（贴图序列表）。负责按主角与结局变体播放谢幕画面与制作人员名单。

## 2.5 三个 EXE 共享的汇编图形库

OPEN/MAIN/END 中存在二进制级相同的例程簇（在三个文件中的特征聚类偏移一一对应），核心是 VGA 平面 blit：

```asm
; 以 4 字节为一组写 4 个位平面（源数据按平面交错）
mov dx, 3C4h        ; VGA Sequencer
mov al, 2           ; Map Mask 寄存器
out dx, al
inc dx
mov al, 1           ; 平面 0
out dx, al
movsb               ; 写平面 0 字节
dec di
shl al, 1           ; 平面 1
out dx, al
movsb
...                 ; 平面 2、3 同理
add di, 50h         ; 下一扫描行（640/8 = 80 字节）
```

另有 Graphics Controller（3CEh）的写模式/旋转设置例程、以及 `AND/OR` 蒙版合成例程（用于带透明的精灵）。该库还包含 `int 15h AX=5000h, BX=0100h, DX=1010h` 调用——向中文 DOS 系统索取 16×16 字型位图函数指针，存入 `cs:[0x22D]` 后以远调用方式逐字取字模。

## 2.6 FMDRV.COM —— FM 音源驱动 TSR（5 055 字节）

- 安装于 **int 66h**（先 `AH=35h` 查询旧向量保存到 0x110，再接管）；若检测到已安装（`AH=FFh` 握手）则自卸载旧实例（`AH=49h` 释放内存）后重装
- 钩住 **int 8（系统计时器）** 做音序播放节拍（代码 0x1C9、0x12AF 两处 `AX=2508h`）
- 直接驱动 **AdLib OPL2**：端口 `388h`（寄存器索引，6 处引用）/ `389h`（数据，2 处引用），含标准的写后延时循环
- 安装检查失败时以退出码 2/4/5/6 区分错误（无声卡 / 已安装 / 内存等）
- 对外 API：int 66h，AH=功能号（播放曲目、停止、设音量等——具体功能号语义未深入逆向）

## 2.7 PW.EXE（缺失文件）

启动器文件名表中存在但游戏目录没有。结合年代与 KOEI 惯例，推测是原版「翻手册找词」式防拷贝验证程序；本中文版流程中启动器从不调用它（MAIN 的退出码只会导向 END.EXE 或回标题）。
