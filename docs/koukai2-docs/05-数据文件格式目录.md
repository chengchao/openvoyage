# 05 数据文件格式目录（全部 59 个文件）

## 5.1 通用结构模式

游戏数据档反复使用三种容器：

1. **LS10/LS11 压缩容器**（魔数 `LS10`/`LS11`，见文档 03）
2. **大端 u32 偏移表档**：文件头是一组升序的 4 字节大端偏移（部分条目的最高字节是属性标志位，如 0x90、0xC0），后接数据块。无魔数。
3. **大端/小端 u16 偏移表档**：小文件用 2 字节偏移，同上。

> 注意：在 x86（小端）平台上使用**大端**偏移表，是 KOEI 跨平台（PC-98/IBM PC/FM Towns 共用数据）开发管线的痕迹。
